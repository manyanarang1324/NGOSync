# NGOSync

NGOSync is a platform designed to streamline operations, donor relations, volunteer coordination, and event synchronization for Non-Governmental Organizations (NGOs).

## Project Structure

```
NGOSync/
 ├── client/   # React + Vite Frontend UI
 └── server/   # Node.js + Express Backend API
```

## Getting Started

### 1. Install Dependencies
```bash
npm run install:all
```

### 2. Configure Environment
Copy `server/.env.example` to `server/.env` and adjust the variables as needed.

### 3. Run Development Servers
```bash
npm run dev
```
